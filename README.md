# Etsy Listing Generator 🎨

AI-powered Etsy listing generator using image analysis.

## Features
- Upload product images
- Get AI-generated Etsy listings
- SEO-optimized titles and descriptions
- Automatic tags and attributes
- Support for Wall Signs and Wall Clocks

## Categories Supported
- 🪧 Wall Sign
- 🕐 Wall Clock
